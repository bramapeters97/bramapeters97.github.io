## Additional required features

API lifecycle tests also pass for single-use invitations, ownership transfer requiring the current password and intended recipient, host-controlled programmes, pending suggestions, voice upload staging, moderation and denial of other viewers' pending voice recordings. Tests verify that disabling memory discovery reaches viewers while administrative settings remain private. Recording precision and IANA timezone validation run server-side.

Shared programme polling is implemented, but cross-household frame synchronisation is not provided. Automatic notification delivery, live AI generation and automatic transcription require external providers.

Additional independent tests pass for live SQLite account/related-record inserts without restart, demo-directory production/custom-database/Host gates, self-scoped account edits, owner-only billing details and invoices, rejected untrusted font/palette IDs, and station-specific eligible collections.
